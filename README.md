A VR-based museum project developed in Unity showing immersive exhibits of famous Indian heritage monuments.  
The project allows users to explore monuments, interact with information hotspots, and experience history in a virtual environment.

## Getting started

1. Clone the repo and open the folder in **Unity 2022.3.62f3** (via Unity Hub).
2. Open the main scene from `Assets/` and press Play.
3. Build target: **Windows (Standalone, 64-bit)**.
